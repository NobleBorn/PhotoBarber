## Homepage Design Direction

PhotoBarber should combine:

1. The uploaded reference website as the **layout reference**
2. The FrameFlow concept as the **style reference**

### Layout reference

The homepage structure should follow the uploaded screenshot's pattern:

- Top navbar with multiple navigation groups
- Large centered hero section
- Short supporting paragraph under the main heading
- Large search bar for tools
- Category filter pills / tabs below the hero
- Tool sections grouped by category
- Each section should have a title and a grid of tool cards
- Tool cards should be compact, informative, and easy to scan

### Style reference

The visual style should still follow the FrameFlow direction:

- Warm off-white page background
- Forest green primary color
- White cards
- Subtle borders and soft shadows
- Rounded corners
- Elegant, modern typography
- Spacious and polished feel
- Minimal and premium interface

Do not copy the uploaded screenshot literally.
Recreate its structure using PhotoBarber branding and the FrameFlow-inspired design system.

## Homepage Structure

### 1. Navbar

Navbar should be horizontally structured like the uploaded reference.

Recommended items:

- Logo / brand name on the left
- Navigation links or dropdowns for:
  - Home
  - Image Editing / Resizing
  - Image Compression
  - Image Converters
  - Image to PDF
- Keep the navbar simple, clean, and responsive

Do not include:
- Sign in
- Pricing
- Upgrade
- Paid plan messaging

### 2. Hero Section

Hero should be centered, not split into left/right columns.

Include:

- Small pill / badge above the heading
  - Example: "100+ FREE TOOLS"
- Large centered heading
  - Example: "Complete Suite of Image Tools"
- Highlight one phrase in the primary green color
- Supporting description below
- Large search bar for finding tools

Hero background can include:
- subtle floating abstract shapes
- soft decorative blobs
- very light visual accents

### 3. Category Tabs

Below the hero, include pill-style category filters such as:

- All Tools
- Editing & Resizing
- Compression Tools
- Format Converters
- Image to PDF

These should look modern and clickable, with:
- white or light backgrounds
- green active state
- rounded pill shape
- subtle borders

### 4. Tool Sections

Organize the homepage into grouped sections.

Example sections:

- Editing & Resizing
- Compression Tools
- Format Converters
- Image to PDF

Each section should contain:
- Section title
- Optional tool count badge
- Responsive grid of compact tool cards

### 5. Tool Cards

Tool cards should be smaller and more numerous than the old FrameFlow bento cards.

Each tool card should contain:
- icon in a colored square or soft-green icon container
- tool title
- short one-line or two-line description

The card style should still match the FrameFlow design system:
- white background
- rounded corners
- subtle border
- soft shadow
- hover lift effect
- elegant spacing

### 6. Responsiveness

Desktop:
- Multi-column card grid

Tablet:
- 2 columns

Mobile:
- 1 column
- tabs scroll horizontally if needed
- search bar remains prominent

### 7. Visual Goal

The final result should feel like:

- the uploaded screenshot's structure
- with FrameFlow's premium green branding and polish

It should look like a real production landing page for a modern image tools website.
